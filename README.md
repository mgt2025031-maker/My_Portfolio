# Interactive Web Portfolio Project — Kasun Wijewardana

A simple and responsive multi-page portfolio website built using **HTML5**, **CSS3**, and **JavaScript** for **Kasun Wijewardana** (Web Designer & Photographer).

## Project Structure
```text
Kasun-Portfolio/
├── index.html       # Home page with intro, profile photo, and services
├── portfolio.html   # Portfolio page showing projects from JSON with popup details
├── contact.html     # Contact details page
├── projects.json    # JSON file storing 6 portfolio projects
├── kasun.jpg        # Profile photo of Kasun Wijewardana
├── style.css        # Responsive design, colors, animations, and Dark Mode
├── script.js        # Hamburger menu, Dark Mode, JSON loading, and category filter
└── README.md        # Project guide and team member roles
